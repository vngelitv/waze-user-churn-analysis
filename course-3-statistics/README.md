# Course 3 – Statistical Analysis

This folder contains the statistical analysis phase of the Waze User Churn Analysis project.

## Work Completed

- Compared mean numbers of drives by device type
- Encoded iPhone and Android device categories
- Used descriptive statistics to compare groups
- Formulated null and alternative hypotheses
- Conducted a two-sample t-test
- Evaluated statistical significance at the 5% level
- Interpreted results for Waze leadership

## Key Finding

The hypothesis test found no statistically significant difference in the mean number of drives between iPhone and Android users.

The p-value was approximately `0.143`, which is greater than the 0.05 significance level. Therefore, the null hypothesis was not rejected.

## Business Insight

Device type alone does not appear to be an important factor in driving behavior. Waze should investigate other behavioral variables when studying engagement and user churn.
