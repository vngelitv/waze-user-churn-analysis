# Course 2 – Exploratory Data Analysis

This folder contains the second phase of the Waze User Churn Analysis project.

## Work Completed

- Explored the distributions of important user behavior variables
- Identified right-skewed variables and high value outliers
- Compared activity days and driving days
- Examined churn rates by device type
- Created kilometers per driving day and session percentage features
- Analyzed behavioral differences between churned and retained users
- Capped selected outliers at the 95th percentile
- Created visualizations to communicate churn patterns

## Key Findings

- Approximately 17% of users churned, while about 83% were retained.
- Churn rates were similar for iPhone and Android users.
- Users who drove longer distances per driving day were more likely to churn.
- Users who drove or used the app more frequently were less likely to churn.
- Several numerical variables were strongly right skewed.
- Many high value observations appeared to represent real user behavior rather than data-entry errors.
